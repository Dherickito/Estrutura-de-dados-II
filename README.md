# Estrutura-de-dados-II

## Sobre o projeto

Este repositório reúne exercícios práticos desenvolvidos em Python com o objetivo de estudar e compreender conceitos fundamentais de programação e estruturas de dados.

Os exercícios abordam referências, listas encadeadas, filas e filas de prioridade, incluindo aplicações práticas, como o gerenciamento de filas de pacientes em uma clínica.

##  Objetivos

- Compreender o funcionamento das estruturas de dados.
- Aprender a manipular referências em Python.
- Implementar e utilizar listas encadeadas.
- Desenvolver operações de inserção e remoção em filas.
- Entender o funcionamento das filas de prioridade.
- Aplicar os conceitos estudados em situações práticas.

##  Conteúdos abordados

### Referências

Estudo sobre referências a objetos em Python e como as variáveis podem acessar e manipular objetos na memória.

### Listas encadeadas

Implementação e compreensão de listas encadeadas, explorando a relação entre os elementos e as referências utilizadas para conectá-los.

### Filas

Estudo da estrutura de dados do tipo fila, que segue o princípio FIFO (*First In, First Out*), no qual o primeiro elemento a entrar é o primeiro a sair.

### Filas de pacientes

Aplicação prática de filas para representar o atendimento de pacientes em uma clínica, organizando a entrada e a ordem de atendimento.

### Filas de prioridade

Estudo de filas em que os elementos são atendidos de acordo com sua prioridade, em vez de seguir exclusivamente a ordem de chegada.

## Tecnologias utilizadas

- **Python** — linguagem de programação utilizada nos exercícios.
